# 青阳平胡规则

版本：v0.4

本文记录青阳县本地平胡麻将的当前规则口径。后续如果补充细节，以本文为规则引擎和测试用例的来源。

## 牌

- 使用万、条、筒、东、南、西、北、中、发、白。
- 不使用花牌。
- 全牌共 136 张，每种牌 4 张。
- 每家门前 17 墩牌。

## 基本玩法

- 只能自摸胡，不能点炮胡。
- 只能碰，不能吃。
- 可以明杠、暗杠、补杠。
- 杠没有独立加分。
- 杠后需要掷骰子，骰子点数为几，就从牌墙后方数第几张补牌。
- 荒庄时庄家连庄。

## 庄家

- 第一局掷骰子决定庄家。
- 庄家胡牌连庄。
- 非庄家胡牌后，下一局由当前庄家的下家坐庄。
- 荒庄连庄。

## 赖子

抓完牌后掷骰子，从后方翻出一张牌。翻出牌的下一张是赖子，按以下顺序循环：

- 万：1万 -> 2万 -> ... -> 9万 -> 1万
- 条：1条 -> 2条 -> ... -> 9条 -> 1条
- 筒：1筒 -> 2筒 -> ... -> 9筒 -> 1筒
- 风牌：东 -> 南 -> 西 -> 北 -> 东
- 箭牌：中 -> 发 -> 白 -> 中

赖子可以充当任意牌，没有额外使用限制。

## 胡牌

当前只定义两种胡牌：

- 平胡
- 跑风胡

胡牌只允许自摸，不允许点炮。

### 平胡

标准 4 组牌加 1 对将即可胡牌。赖子可以补任意缺口。

如果手牌中赖子数量大于等于 2 个，则不能按平胡结算，必须达到跑风才能胡。

### 跑风

任意摸牌前，如果摸到任意一种牌都能开牌，则称为跑风。跑风由系统自动判定，不需要玩家声明。

如果后续启用“缺一门”规则，跑风判定也必须满足缺门限制。也就是说，如果摸到某种牌会破坏缺门，则不能算跑风。

### 缺一门

缺一门作为后续可选规则开关：

- 只检查万、条、筒。
- 东、南、西、北、中、发、白不参与缺门判断。

## 计分

1 分 = 1 欢乐豆。自摸时其他三家分别支付给胡牌者。庄家参与的那一份按庄家分计算：

- 庄家胡牌：三家都按庄家分支付。
- 平家胡牌：庄家按庄家分支付，其他平家按平家分支付。

| 胡牌类型 | 平家每家付 | 庄家每家付 |
| --- | ---: | ---: |
| 平胡 | 5 | 10 |
| 跑风 | 10 | 20 |
| 杠上平胡 | 25 | 30 |
| 直杠 | 60 | 70 |

说明：

- 杠上平胡：杠后补牌自摸平胡。
- 直杠：杠时已经处于跑风状态，杠后胡牌。
- “庄家/头家”当前按同一概念处理。
