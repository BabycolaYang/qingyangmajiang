# 开发路线图

这是项目唯一的任务清单和实现记录入口。按依赖顺序推进，不在完成前跳过前置项。

## 使用规则

- 每次开始工作：从第一个未完成任务开始，或在任务编号后说明阻塞原因。
- 每次完成工作：将 `[ ]` 改为 `[x]`，并在任务下补充“实现记录”。
- 实现记录至少包含：日期、涉及文件、验证命令或人工验证结果。
- 需要讨论但尚未决定的事情放在“决策待定”，不要混入可执行任务。

## 当前重点

- `R1` 至 `R5`：把规则引擎变成可回放、可压测的服务端权威状态机。
- `S1` 至 `S5`：让联机房能够承受断线、重连、解散和重复请求。
- `C1` 至 `C5`：完成 PixiJS 牌桌的基础体验和资源化。
